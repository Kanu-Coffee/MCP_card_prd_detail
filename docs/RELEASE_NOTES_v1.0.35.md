# CardRAG v1.0.35

## 변경 사항

- Worker → MCP 갱신 경로를 공유 로컬 서빙 볼륨으로 전환했습니다. MCP는 검증된 generation을 읽기 전용으로 사용하며, WebDAV는 선택적인 PDF·OCR 백업으로 동작합니다.
- 백업 대기 목록, 내용 해시, 확인 기록과 원격 index를 이용해 증분 백업합니다. 실행 모드와 시간 예산을 지정할 수 있으며, 대기 항목이 없으면 원격 전송을 생략합니다.
- 기존 OCR 캐시의 재사용과 provider/model 복원을 보완했습니다. variant 및 epoch 경계를 유지하며 불필요한 유료 OCR 재처리를 방지합니다.
- 백업 처리량과 실제 HTTP 업로드량을 구분해 기록합니다.

## 운영 인수 근거

- 실제 영향 대상 328건에서 provider 호출 없이 원래 OCR과 variant를 유지했습니다. native 5건의 provider 복원도 확인했습니다.
- 첫 운영 배치: 5,520문서, OCR 5,519건 재사용·1건 신규 처리, exit 0, 로컬 게시 성공.
- 초기 백업: 12,977항목을 46분 31초에 완료했습니다. 대기·유실은 0이며, 원격 index 16,783항목과 로컬 확인 기록이 일치했습니다.
- 후속 배치: OCR 5,520건 전량 재사용, provider 호출·임베딩 캐시 누락·백업 요청 모두 0입니다. MCP의 새 generation과 상품 요약 응답을 확인했습니다.
- 2026-10-10 03시 systemd 실행은 배포 경로 권한 오류로 시작 전에 실패했습니다. 권한 수정 및 운영 UID 접근 검증 후 수동 복구 배치를 완료했습니다. 다음 실제 03시 스케줄 실행은 후속 확인 항목입니다.
