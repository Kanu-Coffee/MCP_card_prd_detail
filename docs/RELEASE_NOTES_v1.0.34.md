# CardRAG v1.0.34

## 변경 사항

- 상품 요약에서 혜택 제목·혜택 상세·이용조건을 문장 문맥과 표 셀의 역할에 따라 분류합니다. 카드사·상품코드별 예외 분기를 사용하지 않습니다.
- 혜택 문장 전체의 이용조건 중복을 줄이고, 전월 실적·한도 표와 거래 예시를 혜택에서 분리합니다. 미적립·미제공 표 셀을 긍정 혜택으로 반환하지 않습니다.
- 연회비 원문 행과 브랜드·등급·본인 대상 및 총액을 보존합니다. 요약 classifier/cache 계약은 `cardrag.product-summary.v4`입니다.
- v1.0.33 이후 추가된 Worker의 PDF·OCR·임베딩 부분 skip 옵션을 포함합니다. 예약 배치 기본 동작과 OCR 재사용은 유지됩니다.

## 검증과 한계

011 인수 기준: 고정 34개와 신규 층화 무작위 30개, 8개 카드사 총 64개 상품의 동일 revision 비교. Reviewer 집중 테스트 118건 통과, Executor MCP 전체 883건 통과. 신고 4개 사례와 연회비 회귀 3개, 부정 혜택 2개 보완을 확인했습니다. 사용자 원래 30개 목록을 재검증한 결과는 아닙니다.

일부 예시·단독 표 금액·빈 제목·5개 출력 제한에 따른 누락은 남을 수 있습니다. 신규 상품에 대한 완벽한 분류를 보장하지 않습니다.

## 발행 및 운영

소프트웨어 패키지 버전은 1.0.34입니다. 공개 이미지 발행은 기존 CI·OCI provenance/SBOM·strict 보안 검사·서명·checksum 절차를 적용합니다. 후보 전체 Worker run·후보 12도구 실호출·gold 평가는 이번 발행 범위에 포함되지 않습니다.

운영 전환은 기존 serving generation/state를 사용하는 MCP 교체만 필요합니다. 재PDF·재OCR·재임베딩은 필요 없습니다. 현재 Worker 이미지와 OpenCode 설정은 유지하며, 공개 이미지 발행 자체가 운영 전환 완료를 뜻하지 않습니다. 운영 전환 결과는 별도 배포 보고서에 기록합니다.
